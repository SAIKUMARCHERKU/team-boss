These are PNG images, with matching file extensions. The page points to these paths. To replace a photo, keep the same filename and refresh the page. Pranay's photo appears in both the hero spotlight and his squad card; everyone else's appears in their squad card.

For GitHub Pages, upload `index.html` and this `photos` folder together, preserving the filenames and folder structure. Missing photos keep their illustrated placeholders. Alternatively, the existing “Add squad photos” tool embeds selected pictures into the downloadable HTML.

All seven supplied photos are included.
